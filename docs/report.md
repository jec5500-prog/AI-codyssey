# 과제 보고서

## 과제 요구사항 정리
- 제출 형식/마감/채점 기준 등 요약

## 구현 내용
- 무엇을 어떻게 구현했는지 항목별로 설명
- 스크린샷/이미지 삽입(아래 이미지 삽입 방법 참고)

## 테스트
- 테스트한 시나리오와 결과

## 회고(선택)
- 잘 된 점, 어려웠던 점, 다음에 개선할 점
- 
| 기능 | 설명 | 상태 |
| --- | --- | :---: |
| 회원가입 | 이메일/비밀번호로 가입 | ✅ |
| 로그인 | 세션 유지, 자동 로그인 | ✅ |
| 게시글 작성 | 마크다운 지원, 이미지 첨부 | ⏳ |







| 항목 | 내용 |
| --- | --- |
| 지원 OS | Windows 11 / macOS 14 |
| 필수 | Node.js 18, npm 9 |
| 설치 | `npm install` |
| 실행 | `npm run start` |








| ID | 시나리오 | 입력 | 기대 결과 | 실제 |
| --- | --- | --- | --- | --- |
| TC-01 | 회원가입 성공 | 유효 이메일/비번 | "가입 완료" 표시 | 통과 |
| TC-02 | 로그인 실패 | 틀린 비밀번호 | 오류 메시지 표시 | 실패(버그 #12) |
