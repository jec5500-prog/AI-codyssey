1. 프로젝트 개요

예시

RSS를 활용하여 부동산 뉴스를 자동으로 수집하고,
중복 여부를 확인한 뒤
새로운 기사만 Notion Database에 저장하고
Discord로 알림을 전송하는 자동화 시스템을 구축하였다.

2. 사용한 자동화 플랫폼

표 하나 넣으면 깔끔합니다.
```
플랫폼	역할
n8n	전체 자동화 워크플로우
Make	동일 기능 비교 구현
RSS Feed	뉴스 수집
Notion	데이터 저장
Discord	알림
```
