# 프로젝트 1. 자동화 도구 비교 구현

## 프로젝트 개요

동일한 자동화 워크플로우를 두 개의 자동화 플랫폼(Make, Zapier)으로 구현하고 비교 분석하였다.

### 구현 목표

Google Sheets에 새로운 업무(Task)가 등록되면,

Priority 값이 High인 경우에만

Discord 채널로 알림을 전송하고,

처리된 데이터를 별도 시트에 저장한다.

---

## 워크플로우 구조

### 공통 워크플로우

```text
Google Sheets
(Trigger)

↓

Filter
(Priority = High)

↓

Discord
(알림 전송)

↓

Google Sheets
(처리 결과 저장)
```

---

## Trigger / Action / Filter 설명

### Trigger

자동화를 시작시키는 이벤트

본 프로젝트에서는

```text
Google Sheets 신규 행 추가
```

를 Trigger로 사용하였다.

---

### Filter

특정 조건을 만족하는 경우만 다음 단계 실행

본 프로젝트에서는

```text
Priority = High
```

조건을 사용하였다.

---

### Action

Trigger 이후 수행되는 작업

본 프로젝트에서는

```text
Discord 메시지 전송
Google Sheets 저장
```

을 Action으로 사용하였다.

# Make vs Zapier 비교 분석

## 구현 과정 요약

동일한 워크플로우를 Make와 Zapier에서 각각 구현하였다.

두 도구 모두 Trigger → Filter → Action 구조를 지원하였으며 실제 Discord 알림 전송까지 정상 동작을 확인하였다.

---

## 비교 분석

| 비교 항목     | Make             | Zapier     |
| --------- | ---------------- | ---------- |
| UI/UX     | 시각적 연결 방식        | 단계별 마법사 방식 |
| 학습 난이도    | 중간               | 쉬움         |
| 초보자 친화성   | 보통               | 높음         |
| 워크플로우 가시성 | 매우 좋음            | 보통         |
| 설정 방식     | 전체 흐름을 한 화면에서 구성 | 단계별 구성     |
| 연동 서비스 수  | 매우 많음            | 매우 많음      |
| 무료 플랜     | 제공               | 제공         |
| 실행 로그 확인  | 상세               | 비교적 단순     |
| 복잡한 자동화   | 강점               | 상대적으로 제한   |
| 간단한 자동화   | 가능               | 매우 적합      |

---

## Make 장점

* 전체 흐름을 한 화면에서 확인 가능
* Router, Filter 구성 편리
* 복잡한 자동화 구현에 유리
* 시각적 이해가 쉬움

### Make 단점

* 초보자에게 다소 복잡하게 느껴질 수 있음
* 초기 학습 필요

---

## Zapier 장점

* 설정이 매우 단순함
* 초보자 접근성이 높음
* 단계별 안내가 친절함
* 빠른 구축 가능

### Zapier 단점

* 복잡한 워크플로우 구현 시 다소 불편
* 시각적 구조 확인이 어려움

---

## 어떤 상황에 적합한가?

### Make

추천 상황

* 복잡한 자동화
* 다수의 조건 분기
* 데이터 처리 중심 업무

---

### Zapier

추천 상황

* 간단한 업무 자동화
* 빠른 구축
* 비개발자 사용자

---

## 프로젝트 1 결론

동일한 자동화 구조를 Make와 Zapier에서 구현하였다.

두 도구 모두 자동화 구현이 가능하였으며,

초보자 친화성은 Zapier,

복잡한 자동화 구현은 Make가 상대적으로 우수하다고 판단하였다.

### UI/UX 비교

Make는 시나리오가 시각적으로 표현되어 전체 흐름을 이해하기 쉬웠다. 모듈 간 연결 관계를 한눈에 파악할 수 있어 초보자도 자동화 구조를 이해하기 수월했다.

Zapier는 단계별 설정 화면이 직관적으로 구성되어 있어 처음 사용하는 사용자가 빠르게 설정할 수 있었다. 다만 복잡한 흐름을 한 화면에서 보기에는 Make보다 제한적이었다.
