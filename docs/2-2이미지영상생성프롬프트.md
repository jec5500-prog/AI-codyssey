# Do Drip AI Commercial Project
## Project Overview

Do Drip is a premium specialty coffee brand built around the message:
"We Brew Rest, Not Just Coffee."

This project was created using generative AI tools for image, video, and audio production.

## AI Tools Used
- Image Generation: Sora
- Video Generation: Sora 2, CapCut AI Video
- Audio Generation: Suno
- Editing: DaVinci Resolve
