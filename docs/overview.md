# AI 기반 회의록 요약 자동화 시스템

## 과업 정의
- 비정형 회의록 데이터를 입력받아 다음 항목을 자동 추출하는 업무 자동화 시스템 구축
- 회의 목적, 핵심, 논의사항, 결정사항, Action, Items, 리스크 및 이슈확인 필요 사항

## 목적 효과
- 정리 시간 단축, 누락&오해 최소화, 일관된 보고서 포맷 확보



## LLM 모델 비교 및 선정 보고서
### 비교 목적
- 동일 과업(회의록 요약)에 3종 LLM을 투입해 정량&정성 축으로 비교하고 최적 모델을 선정

### 무료 버전 사용 시 제한사항
- GPT, Claude 및 Gemini는 무료 버전 사용으로 인해 다음과 같은 제한이 존재함.
- - 사용량 제한 발생 가능 / 최신 모델 선택 제한 가능 / 장문 입력 처리량 제한 가능
 

## 동일 입력 내용
### 업무 과엽
- 회의록 요약 자동화
### 입력 데이터
- 신규 AI 회의록 요약 서비스 베타 출시 준비 회의록(원본 회의록 별첨)


### LLM 비교 실험용 공통 프롬프트
    당신은 프로젝트 매니저(PM) 출신의 업무 자동화 코치입니다.
    
    목표 회의록을 분석하여 아래 항목으르 추출하십시오.
    * 회의목적
    * 핵심 논의사항
    * 결정사항
    * Action Item
    * 리스크 및 이슈
    * 확인 필요 사항
    
    중요규칙
    1. 회의록에 없는 정보는 생성하지 마십시오.
    2. 추측하지 마십시오.
    3. 담당자 또는 일정이 불명확하면 "확인 필요"로 표시하십시오.
    4. 사실과 추론을 구분하십시오.
    5. 최종 출력 형식으르 반드시 준부하십시오.
    6. 실명은 사용하지 말고 역할명으로 표현하십시오.
    7. 내부적으로 단계적으로 검토하되 추론 과정은 출력하지 마십시오.
    8. 최종 답변에는 핵심 근거를 최대 3개만 제시하십시오.

## 회의록 원문
    참석자 : PM, 백엔드 개발자, 프론트엔드 개발자, 마케팅 담당자, 운영 담당자
    
    회의주제 : 신규 AI 회의록 요약 서비스 베타 출시 준비
    
    회의 내용
    PM: 현재 베타 출시 목표일은 6월 20일입니다. 출시 일정이 가능할지 확인이 필요합니다.
    백엔드 개발자: 현재 요약 엔진 성능은 목표 수준에 근접했습니다. 다만 긴 회의록 처리 시 응답 속도가 느려지는 문제가 있습니다.
                최적화 작업이 약 2주 정도 필요할 것으로 예상됩니다.
    프론트엔드 개발자: UI는 거의 완료되었습니다. 하지만 모바일 환경에서 일부 화면 깨짐 현상이 발견되었습니다.
    PM: 출시 일정에 영향을 줄 수 있는 수준인가요?
    프론트엔드 개발자: 심각한 수준은 아니지만 수정은 필요합니다.
    마케팅 담당자: 출시 2주 전부터 사전 홍보 캠페인을 시작하는 것이 좋겠습니다. 광고 예산은 아직 확정되지 않았습니다.
    운영 담당자: 고객 문의 대응 프로세스가 아직 준비되지 않았습니다. FAQ 초안도 작성 중입니다.
    PM: 고객 지원 프로세스는 출시 전까지 준비되어야 합니다.
    백엔드 개발자: API 비용이 예상보다 높을 수 있습니다. 월 운영비가 기존 예상보다 증가할 가능성이 있습니다.
    PM: 그 부분은 재검토가 필요합니다.
    마케팅 담당자: 서비스 소개 랜딩 페이지는 다음 주까지 초안 제작이 가능합니다. 
    PM: 좋습니다. 현재 기준으로 베타 출시 일정은 유지하되, 기술적 이슈 해결 여부를 다음 회의에서 다시 검토합시다.
