AI 자동화 과제 2
YouTube RSS를 활용한 영상 등록 자동 알림 시스템 구축
과제명

YouTube RSS Feed를 활용하여 신규 영상이 등록되면 Notion 데이터베이스에 자동 저장하고 Discord로 알림을 전송하는 자동화 워크플로우 구축

1. 과제 개요

본 과제에서는 YouTube 채널의 RSS Feed를 이용하여 새로운 영상이 업로드되면 자동으로 감지하고,

Notion 데이터베이스에 저장
Discord 전용 채널에 알림

이 동시에 수행되는 자동화 시스템을 구축하였다.

자동화 플랫폼은 n8n을 사용하였다.

2. 사용한 서비스
n8n
YouTube RSS Feed
Notion Database
Discord Bot
3. 워크플로우 구성

워크플로우는 다음과 같이 설계하였다.

RSS Feed Trigger

↓

IF (Shorts 영상만 통과)

↓

Notion Get Many

↓

IF (이미 등록된 영상인지 확인)

↓

Notion Create Database Page

↓

Discord Send Message

(워크플로우 전체 캡처 삽입)

4. 각 노드 설명
① RSS Feed Trigger

YouTube RSS Feed를 구독하여 새로운 영상 업로드를 감지한다.

전달받는 주요 데이터는 다음과 같다.

title
link
pubDate
author
id

(RSS Trigger 실행 화면 캡처)

② IF 노드

RSS Feed에는 Shorts 외에도 다양한 영상이 포함될 수 있으므로 조건을 이용하여 원하는 데이터만 통과하도록 구성하였다.

필요한 영상만 다음 단계로 전달된다.

(IF 노드 설정 캡처)

③ Notion Get Many

Notion Database에서 이미 저장된 영상인지 조회한다.

조회 조건은

링크(URL)

또는

영상 ID

기준으로 검색하도록 설정하였다.

동일한 영상이 이미 존재하면 중복 등록을 방지한다.

(Get Many 설정 캡처)

5. 테스트 결과

테스트를 위해 RSS Feed를 실행한 결과

새로운 영상이 감지되었으며

자동으로

① Notion Database 저장

② Discord 알림

두 과정이 모두 정상적으로 수행되었다.

또한 이미 등록된 영상은 중복 생성되지 않는 것을 확인하였다.

6. 문제 해결 과정

자동화 과정에서 다음과 같은 문제를 해결하였다.

(1) Get Many 결과가 비어있는 문제

Get Many 노드는 검색 결과가 없으면 빈 Item을 반환하였다.

이를 활용하여

두 번째 IF 노드에서 신규 데이터 여부를 판단하도록 수정하였다.

(2) URL Property 오류

초기에는

URL is not a property that exists.

오류가 발생하였다.

원인은 Notion Database의 실제 속성명이

링크

였기 때문이었다.

n8n에서도 동일한 속성명을 선택하여 해결하였다.

(3) IF 노드 타입 오류

초기에는

Wrong type:
'1' is a number but was expecting a string

오류가 발생하였다.

비교 대상을

{{ $json.id }}

으로 수정하여 정상 동작하도록 해결하였다.

7. 최종 결과

최종적으로

YouTube RSS Feed에서 새로운 영상이 업로드되면

자동으로

Notion Database 저장
Discord 알림 전송

이 동시에 수행되는 자동화 시스템을 구축하였다.

중복 등록도 방지되어 안정적으로 동작하는 것을 확인하였다.
