# 📌 프로젝트 2. YouTube RSS 자동 수집 및 Discord 알림 자동화

## 프로젝트 개요

YouTube RSS Feed를 활용하여 새로운 영상이 업로드되면 자동으로 감지하고,

- Notion 데이터베이스에 저장
- Discord 전용 채널에 알림

까지 자동으로 수행되는 워크플로우를 구축하였다.

---

# 사용 기술

- n8n
- YouTube RSS Feed
- Notion API
- Discord Bot API

---

# 전체 워크플로우

```
RSS Feed Trigger
        │
        ▼
     IF (제목 필터)
        │
        ▼
Get Many Database Pages
        │
        ▼
 IF (중복 여부 확인)
        │
   ┌────┴────┐
   │         │
중복O      중복X
 종료         │
              ▼
      Create Database Page
              │
              ▼
      Discord Message
```

# 4. 두 번째 IF 노드 (중복 체크)

RSS에서 전달받은 영상 ID와

Notion Database에 저장되어 있는 ID를 비교하였다.

비교식

```
{{ $json.id }}
```

이미 존재하는 영상이면

```
True
→ 종료
```

존재하지 않는 경우

```
False
→ Create Database Page
```

로 이동하도록 구성하였다.

# 5. Create Database Page

중복되지 않은 영상만 Notion Database에 자동 저장하였다.

저장 항목

| Property | 값 |
|----------|----|
| Title | RSS title |
| Link | RSS link |

(업로드일은 이번 과제에서는 제외)

사용한 Expression

Title

```javascript
{{ $('RSS Feed Trigger').item.json.title }}
```

URL

```javascript
{{ $('RSS Feed Trigger').item.json.link }}
```

# 6. Discord 알림

새로운 영상이 등록되면 Discord Bot을 이용하여 전용 채널에 메시지를 전송하였다.

메시지 형식

```
🔥 새로운 YouTube 영상이 등록되었습니다!

제목
전기차 타고 있다면 이 문자, 그냥 넘기지 마세요!

링크
https://youtube.com/...

업로드
2026-07-08T09:05:14Z
```

사용한 Expression

제목

```javascript
{{ $('RSS Feed Trigger').item.json.title }}
```

링크

```javascript
{{ $('RSS Feed Trigger').item.json.link }}
```

업로드일

```javascript
{{ $('RSS Feed Trigger').item.json.pubDate }}
```
